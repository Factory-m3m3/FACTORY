The first Factory — before on-chain metadata

From August to September 2026, every launch on factory.apexpad.io went through the contracts below. They are still on-chain, unchanged, and nothing about the tokens they created has changed: liquidity is still held by each token's custodian, ownership is still renounced, and every proof page is still online.

New launches now use the new Factory, which writes the logo, description and social links directly into the token contract — at the same address on all 7 chains: 0xB7DA71D51a6946f3c5616181Ec84e7501cb1A75c

Each launch through these contracts is atomic: token, pool, locked position, FeeSplitter and both ownership renounces happen in one single transaction — or nothing happens.

What stays exactly the same

  • 100% of the supply in a single-sided position, held by a custodian with no withdrawal function.
  • Token and custodian ownership renounced at launch.
  • Swap fees split 50/50 creator/platform, forever.
  • Anyone can still claim fees (collect() then release()) on the explorer.

What the new Factory adds

  • Logo (stored permanently on Arweave), description and links written in the token contract — readable by anyone with getTokenInfo().
  • A two-way link: the token names its Factory, and the Factory confirms it (isLaunchedHere).
  • Proof pages published only after an on-chain check.

Tokens launched with the previous Factory

They are all listed in the launch catalog with their original proof pages. Their logos and links were never on-chain, so aggregators still need them submitted by hand (DexScreener, GeckoTerminal, explorers).
